# 🚀 股票投資分析工具 (Stock Analysis Tool v3.0)

自動分析股票的 EMA、BIAS 等技術指標，搭配**動能分析**和**趨勢判斷**，快速判斷「今天可不可以買」！

## 📋 功能特性

✅ **自動分析技術指標**
- EMA12 & EMA26 (指數移動平均線)
- SMA20 (簡單移動平均線)  
- BIAS% (偏離率)
- MACD (指數平滑異同平均線)
- 股價漲跌 %

✅ **v3.0 智能買賣訊號** ⭐ 新升級
- 🟢 可以買 / 💪 持有 / 🔴 減碼 / ⚪ 觀望
- 基於**動能加速度**、**趨勢強度**、**反彈確認**三大改進
- 區分強牛市 vs 弱熊市（同一 BIAS 值決策不同）

✅ **三大改進機制**（v3.0 新增）
- **改進❶**: 過熱區智能判斷（區分強勢加速 vs 動能減弱）
- **改進❷**: 動能加速度偵測（追蹤 BIAS 方向變化）
- **改進❸**: 回檔確認機制（超跌區等反彈後再進場）

✅ **批量分析投資組合**
- 一次分析多個股票
- 自動生成摘要報告

✅ **Excel 匯出**
- 自動導出詳細分析到 Excel
- 包含所有技術指標和 v3.0 新訊號

✅ **BIAS 策略回測** (進階功能)
- 測試不同 BIAS 進場點的勝率
- 找出最優進場價位

---

## 🎯 v3.0 核心改進

### 改進❶: 過熱區智能判斷
**問題**: v2.0 在 BIAS > 5% 時盲目減碼，錯過強牛市機會  
**解決**: 根據動能方向 + 趨勢強度判斷  
**結果**: 強勢加速 → 💪 持有 | 動能減弱 → 🔴 減碼

### 改進❷: 動能加速度偵測  
**問題**: v2.0 無法區分 BIAS 15% 是加速還是減速  
**解決**: 追蹤前日 BIAS，計算環比變化  
**結果**: 同一 BIAS 值，加速 ↑ vs 減速 ↓ 決策不同

### 改進❸: 回檔確認機制
**問題**: v2.0 在超跌區直接進場，可能抄底摔  
**解決**: 等待 BIAS 環比上升才進場  
**結果**: 避免假突破，只在反彈確認後進場

詳見: [V3_IMPROVEMENTS.md](../V3_IMPROVEMENTS.md) (完整技術文檔)

## 🎯 買賣訊號說明

### 📊 修正版決策邏輯 (v2.0)

基於 **BIAS 偏離率** 和 **EMA 趨勢濾網** 的新決策規則：

| BIAS 範圍 | 訊號 | 行動 | 說明 |
|---------|------|------|------|
| **< -5%** | 🔵 超跌 | 分批買 | 股價大幅低於均線，極具吸引力 |
| **-5% ~ +3%** | 🟢 合理 | 可布局 | 價格在合理區間，適合進場 |
| **+3% ~ +5%** | 🟡 偏熱 | 不追 | 股價偏離均線，暫不跟進 |
| **> +5%** | 🔴 過熱 | 等回檔/減碼 | 股價漲過頭，應該減碼 |

### 🔑 核心規則：趨勢濾網

**只有當 EMA12 > EMA26 才允許做多 ✅**

- 如果 BIAS 條件看好，但 EMA12 ≤ EMA26：訊號變為 **🟠 等待** 或 **⚪ 觀望**
- 即使超跌也要確認上升趨勢才進場，避免逆勢交易

### 訊號詳解

| 訊號 | 符號 | 觸發條件 | 建議行動 |
|------|------|--------|--------|
| **強烈買入** | ✅ | BIAS < -5% + EMA12 > EMA26 | 大膽進場 |
| **可以買** | 🟢 | -5% ≤ BIAS ≤ +3% + EMA12 > EMA26 | 分批進場 |
| **等待** | 🟠 | BIAS 看好但 EMA12 ≤ EMA26 | 觀望等機 |
| **觀望** | ⚪ | +3% < BIAS ≤ +5% | 不動作 |
| **減碼** | 🔴 | BIAS > +5% | 部分出場 |

## 📈 技術指標說明

### EMA (指數移動平均線)
- EMA12：短期趨勢，反應快速
- EMA26：長期趨勢，較為平穩
- **關鍵濾網**：EMA12 > EMA26 時才允許做多

### BIAS (偏離率)
計算公式：`(收盤價 - SMA20) / SMA20 × 100%`

**新的判斷標準（v2.0）：**
- **BIAS < -5%**：超跌，分批買進
- **-5% ~ +3%**：合理區間，可布局
- **+3% ~ +5%**：偏熱，建議不追
- **BIAS > +5%**：過熱，等回檔或減碼

**舊標準（已棄用）：**
- ~~BIAS > 3%：超買~~ → 現改為 > 5% 才視為過熱
- ~~BIAS < -3%：超賣~~ → 現改為 < -5% 才視為超跌

### MACD (指數平滑異同平均線)
- MACD > 0：看漲
- MACD < 0：看跌
- 0 軸上下穿越是轉折點

### SMA20 (簡單移動平均線)
- 反映 20 天的平均價位
- 常見的支撐/阻力位

## 💡 使用建議

### 基礎用法
1. 每天早開盤前運行 `python StockAnalyzeMain.py --portfolio`
2. 查看摘要報告，找「✅ 強烈買入」的股票
3. 自動生成的 Excel 檔案可保存記錄

### 進階用法
1. 針對特定股票進行 `--backtest` 找出最優進場點
2. 根據回測結果調整進場 BIAS 閾值
3. 結合其他基本面分析，做出投資決策

### ⚠️ 注意事項
- ❌ 本工具僅供參考，不構成投資建議
- ❌ 過去績效不代表未來表現
- ✅ 建議結合其他分析方法使用

## 🐛 故障排除

### 問題：無法連接到網絡
**解決**：檢查網絡連接，yfinance 需要下載股票數據

### 問題：股票代號無效
**解決**：確保使用正確的台灣股票代碼格式（5 位數或股票代號）

### 問題：Excel 文件打不開
**解決**：檢查文件是否被其他程序占用，或重新運行以生成新文件

### 問題：某個股票分析失敗
**解決**：查看控制台的錯誤信息，某些新上市股票可能暫無充足數據
