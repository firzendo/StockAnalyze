# 📊 v3.0 決策邏輯說明（升級版）

## 🎯 v3.0 核心改進

v3.0 引入了**三大改進機制**，讓決策更精準：
- ✅ **改進❶**: 過熱區智能判斷（區分強牛 vs 弱熊）
- ✅ **改進❷**: 動能加速度偵測（追蹤 BIAS 方向變化）
- ✅ **改進❸**: 回檔確認機制（避免假突破進場）

詳見 [V3_IMPROVEMENTS.md](../V3_IMPROVEMENTS.md)（完整技術文檔）

## 新的訊號生成規則（v3.0）

### 1️⃣ BIAS 4 區間判斷表

| BIAS 範圍 | 訊號 | 特徵 | 說明 |
|---------|------|------|------|
| **< -5%** | 🔵 超跌 | 需要反彈確認 | 股價大幅低於均線，等待反彈後進場 |
| **-5% ~ +3%** | 🟢 合理 | 安全進場區 | 價格在合理區間，適合直接進場 |
| **+3% ~ +5%** | 🟡 偏熱 | 需要動能確認 | 股價偏離均線，只追加速信號 |
| **> +5%** | 🔴 過熱 | **智能判斷** | 股價高於均線，但**動能和趨勢**決定動作 |

**新增❶**: 過熱區 (> 5%) 現在根據動能方向 + 趨勢強度自動判斷

---

### 2️⃣ 動能分析（v3.0 新增）

| BIAS 變化 | 判斷 | 含義 | 信號 |
|---------|------|------|------|
| 環比上升 ⬆️ | 加速 | 買盤力道增強 | 強看多 💪 |
| 環比下降 ⬇️ | 減速 | 買盤力道減弱 | 觀望或減碼 🔴 |
| 環比持平 ➡️ | 穩定 | 力道維持 | 中立 ⚪ |

**新增❷**: 同一 BIAS 值，現在能區分上升力道 vs 下降力道

---

### 3️⃣ 趨勢強度判斷（v3.0 新增）

| EMA12 vs EMA26 距離 | 趨勢 | 強度 | 做多評分 |
|------------------|------|------|--------|
| > 2.0% | 強上升趨勢 | 💪 強 | ⭐⭐⭐⭐⭐ |
| 0.5% ~ 2.0% | 正常上升趨勢 | 📈 正常 | ⭐⭐⭐ |
| < 0.5% 或向下 | 弱勢或下跌 | ⚠️ 弱 | ⭐ |

**新增❸**: 用 EMA 乖離率量化趨勢強度

## 📈 v3.0 決策邏輯流程

```
開始分析
    ↓
提取數據 (BIAS, 前日BIAS, EMA12, EMA26)
    ↓
計算 3 個分析層面
├─ 動能: BIAS_CHANGE = 今日BIAS - 前日BIAS
├─ 趨勢: EMA距離 = (EMA12 - EMA26) / EMA26 * 100%
└─ 反彈: BIAS環比上升?
    ↓
進入 4 區間決策
    ↓
┌──────────────────────────────────────────────────┐
│ BIAS < -5% (🔵 超跌)                             │
│ ├─ 反彈確認 (BIAS環比↑)? → 🟢 可以買            │
│ └─ 還在下跌 (BIAS環比↓)? → ⚪ 觀望              │
├──────────────────────────────────────────────────┤
│ -5% ≤ BIAS ≤ +3% (🟢 合理)                      │
│ └─ 所有情況 → 🟢 可以買                          │
├──────────────────────────────────────────────────┤
│ +3% < BIAS ≤ +5% (🟡 偏熱)                      │
│ ├─ 動能加速 + 趨勢強? → 🟡 可以買               │
│ └─ 動能減弱或趨勢弱? → ⚪ 觀望                   │
├──────────────────────────────────────────────────┤
│ BIAS > +5% (🔴 過熱) ⭐ v3.0 新邏輯            │
│ ├─ 強勢加速 (BIAS↑ + 趨勢強)                    │
│ │  → 💪 持有                                    │
│ ├─ 動能減弱 (BIAS↓ + 趨勢弱)                    │
│ │  → 🔴 減碼                                    │
│ └─ 其他情況                                      │
│    → ⚪ 觀望                                     │
└──────────────────────────────────────────────────┘
```

## 🎯 v3.0 訊號詳解

### 🔵 超跌 (BIAS < -5%)
- **判斷條件**: BIAS 遠低於 20 日均線
- **v3.0 新增**: 需要**反彈確認** (BIAS 環比上升)
- **進場信號**: ✅ 只在反彈已確認時進場
- **避免問題**: 不在最低點前一秒進場

**範例**:
```
前日: BIAS -10%  ❌ 還在下跌中 → ⚪ 觀望
今日: BIAS -8%   ✅ 已開始反彈 → 🟢 可以買
```

### 🟢 合理 (BIAS -5% ~ +3%)
- **判斷條件**: 價格在合理區間
- **v3.0 邏輯**: 直接進場 (無須額外確認)
- **進場信號**: 🟢 可以買（最安全的進場區）
- **優勢**: 成功率最高

### 🟡 偏熱 (BIAS +3% ~ +5%)
- **判斷條件**: 股價開始偏離均線
- **v3.0 邏輯**: 只追**動能加速**信號
- **進場信號**: 🟡 可以買（需要確認趨勢）
- **風險**: 追高風險較高

### 💪 持有 (BIAS > +5% + 強勢加速) ⭐ v3.0 新增
- **判斷條件**:
  - BIAS > 5%（過熱區）
  - BIAS 環比上升 ⬆️（動能加速）
  - EMA12 > EMA26 距離 > 2%（強趨勢）
- **進場信號**: 💪 持有 （不減碼，繼續持有）
- **情境**: 強勢牛市，不應該減碼

**實際案例**: 
```
0050 (2024-04-24)
BIAS: 11.67% ↑ (vs 前日 8.5%)
EMA距離: 3.2% (> 2%)
↓
v2.0: 🔴 減碼 (盲目)
v3.0: 💪 持有 (聰明)
```

### 🔴 減碼 (BIAS > +5% + 動能減弱)
- **判斷條件**:
  - BIAS > 5%（過熱區）
  - BIAS 環比下降 ⬇️（動能轉弱）
  - 或 EMA 距離 < 0.5%（弱趨勢）
- **進場信號**: 🔴 減碼 （獲利減碼，避免反轉）
- **情境**: 泡沫破裂或動能已轉弱

### ⚪ 觀望
- **判斷條件**: BIAS > 5% 但動能/趨勢模糊
- **進場信號**: ⚪ 觀望 （等待確認）
- **風險**: 不清楚方向時不動作

## 🔑 核心原則（v3.0 版本）

1. **動能優先**（新增）
   - 區分上升 ⬆️ vs 下降 ⬇️
   - 同一 BIAS 值決策不同

2. **趨勢強度判斷**（新增）
   - EMA 距離量化趨勢
   - 強趨勢 > 2%，弱趨勢 < 0.5%

3. **反彈確認**（新增）
   - 超跌區必須等反彈確認
   - 避免抄底摔

4. **分層進場**
   - BIAS < -5%: 反彈確認後進
   - -5% ~ 3%: 直接可進
   - 3% ~ 5%: 動能確認後進
   - > 5%: 智能判斷持有/減碼

5. **避免逆勢**
   - EMA12 > EMA26 才能做多
   - 弱勢中再便宜也要謹慎
