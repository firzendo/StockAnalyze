# 📋 v3.0 快速參考卡

## 三大改進一眼看

### 改進 ❶: 過熱區智能判斷
| BIAS | 趨勢狀態 | v2.0 | v3.0 | 原因 |
|------|--------|------|------|------|
| 12% | EMA12 > EMA26 (差距 3%) + BIAS 環比上升 | 🔴 減碼 | 💪 持有 | 強勢加速，不該減碼 |
| 10% | EMA12 > EMA26 (差距 1.5%) + BIAS 環比下降 | 🔴 減碼 | 🔴 減碼 | 動能轉弱，確認減碼 |
| 6% | EMA12 < EMA26 | 🔴 減碼 | 🔴 減碼 | 空頭市場，減碼 |

**核心改變**: BIAS > 5% 時，不再盲目減碼，改為根據 EMA 距離 + 動能方向判斷

---

### 改進 ❷: 動能加速度
| 情境 | BIAS | 前日 BIAS | 變化 | 解讀 | 信號 |
|------|------|---------|------|------|------|
| 加速上升 | 12% | 8% | +4% | 動能持續加速 | ⬆️ 強買 |
| 減速上升 | 8% | 15% | -7% | 漲勢已減弱 | ↗️ 弱買 |
| 加速下跌 | -8% | -5% | -3% | 跌勢加速 | ⬇️ 強賣 |
| 減速下跌 | -3% | -8% | +5% | 跌勢已停，反彈在望 | ↖️ 弱賣轉買 |

**新能力**: 區分同一 BIAS 值的上升 vs 下降動能

---

### 改進 ❸: 回檔確認
```
超跌區 (BIAS < -5%):
  └─ 前日 BIAS: -10%, 今日 BIAS: -8% (環比 +2%)
     → ✅ 已開始反彈 = 可進場

  └─ 前日 BIAS: -8%, 今日 BIAS: -9% (環比 -1%)
     → ❌ 還在下跌 = 等待，別進場

合理區 (-5% ~ 3%):
  → ✅ 所有情況可進場
```

**新能力**: 避免在最低點前一秒進場

## 常見問題

**Q: 為什麼我的股票 BIAS 10% 還是 🟢 可買 而不是 💪 持有？**
A: 檢查 EMA12 vs EMA26 距離是否 > 2%，以及 BIAS 是否環比上升。距離 < 0.5% 或 BIAS 環比下降時會顯示 🟢。

**Q: 超跌區 (BIAS < -5%) 為什麼沒有進場訊號？**
A: v3.0 要求 BIAS 環比上升才進場。如果 BIAS 還在下跌 (e.g., -10% → -11%)，訊號會是 ⚪ 觀望。

**Q: 我想關閉回檔確認機制嗎？**
A: 不建議。這是 v3.0 最重要的改進，避免假突破的關鍵機制。
